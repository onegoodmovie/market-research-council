# Public Data Boundary

This repository is a clean-room demonstration of an agent coordination pattern.

## Included

- Synthetic market snapshots
- Generic evidence contracts
- Illustrative, simplified research rules
- An explicit challenge and audit stage
- Reproducible tests

## Excluded

- Employer or client information
- Licensed or proprietary market data
- Production source code and configuration
- Private research thresholds and historical labels
- Trading recommendations, positions, or performance records
- API keys, account identifiers, and local file paths

The project is for engineering demonstration and education. Its output is not investment advice.
